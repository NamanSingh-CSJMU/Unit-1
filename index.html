1.1 Before C — What is a Program?

A computer only understands machine language — pure binary 0s and 1s. A program is a precise sequence of instructions that tells the computer exactly what to do. Since writing 0s and 1s by hand is impossible, we use programming languages — a vocabulary + grammar that a translator converts into machine code.

Levels of programming languages

🔩 Low-level languages
Machine Language · Assembly
Close to hardware. Fast, but nearly unreadable for humans and machine-dependent (written differently for every CPU).
⚙️ Middle-level languages
C · C++
Combine the power of assembly (memory, bits) with the readability of high-level languages. This is exactly where C sits.
🚀 High-level languages
Python · Java · C#
English-like, machine-independent, easy to write — but further from hardware and generally slower.

1.2 What is C?

C is a general-purpose, middle-level, compiled, case-sensitive programming language developed by Dennis Ritchie in 1972 at Bell Laboratories. It is the most important language ever — the OS, databases and even the Python you use daily are written in C.

🧱 High-level side
Functions, loops, if-else, arrays, structures — familiar, human-friendly, portable syntax.
⚙️ Low-level side
Pointers, bitwise operators, direct memory control — the raw power that makes C blazing fast.

Where is C actually used today?

🖥️ Operating Systems
UNIX, Linux and the Windows kernel are written in C. Your OS is a giant C program.
📟 Embedded & IoT
Cars, washing machines, satellites, medical devices, Arduino projects run on C.
🛠️ Compilers & Tools
GCC, Git, the Python interpreter (CPython) and Node.js core are all C code.
🗄️ Databases
MySQL, PostgreSQL and Redis are built on C for raw performance.
🎮 Games & Engines
Performance-critical parts of game engines and graphics libraries use C.
🧠 Foundation
C++, Java, C#, JavaScript, Python and Rust all borrow syntax from C.

1.3 History of C — The Complete Story

C was developed by Dennis M. Ritchie between 1969–1973 (first usable version in 1972) at Bell Telephone Laboratories, Murray Hill, New Jersey, USA — mainly to rewrite the UNIX operating system on the DEC PDP-11, so the OS would not need a new assembly rewrite for every machine.

🎓 Exam answer ready
C was developed by Dennis Ritchie in 1972 at Bell Labs, mainly to write UNIX. Its direct ancestor is B (Ken Thompson, 1970), from BCPL (Martin Richards, 1967).

Timeline — 1950s to today

1
1960ALGOL 60
International committee language with a truly formal grammar — the first structured language. C inherited its block structure and begin…end idea.
2
1963CPL — Combined Programming Language
Built at Cambridge & London universities. More practical than ALGOL, but large and slow to implement.
3
1967BCPL — Basic CPL
Martin Richards trimmed CPL to the essentials: a tiny, typeless language perfect for compilers and system tools.
4
1969–70B Language
Ken Thompson (a colleague of Ritchie) rewrote BCPL for the UNIX project on a PDP-7. B was also typeless and word-based — inefficient on the new byte-addressed PDP-11.
★
1972C Language
Ritchie added data types (char, int, float), arrays, structures and pointers to B — a fast, small, portable language. In 1973 UNIX itself was rewritten in C, the first major OS built in a high-level language.
6
1978K&R C — "The C Bible"
Brian Kernighan & Dennis Ritchie published "The C Programming Language". The book (not a committee) became the de-facto standard — still the best-selling programming book.
7
1983–89ANSI C (C89)
Every compiler had added its own extras, so ANSI formed committee X3J11 in 1983 to standardise C. Approved in 1989 (ANSI C / C89); ISO adopted it in 1990 as C90. This is what textbooks teach.
8
1999C99
Added // comments, long long, declarations anywhere in a block, inline functions, stdbool.h and binary-ready math.
9
2011C11
Multi-threading (threads), anonymous struct members, bounds-checked function family, _Static_assert.
10
2018C17
A maintenance release — bug fixes and clarifications of C11, no new features.
11
2024C23 (latest)
The newest standard: real bool type, constexpr, designated initializers in any order, better UTF-8 handling. Older standards remain the most used in colleges.

The evolution chain — memorise this order

ALGOL➜ CPL➜ BCPL➜ B➜ C
💡 Why is it named "C"?
Because it succeeded B, which succeeded BCPL. Ritchie simply used the next letter after B — and C. (A short-lived language D existed earlier, but C was the one that stuck.)

1.4 Features (Characteristics) of C

🧩 Simple & Clean Syntax
Only 32 keywords and a tiny set of building blocks. English-like — a beginner can write working code in one sitting.
⚡ Fast & Efficient
Compiles directly to machine code with almost no overhead — usually as fast as hand-written assembly.
🎚️ Middle-Level Language
High-level structure plus low-level bit/byte control — one language for both apps and system software.
📦 Structured Language
Problems are split into small functions and { } blocks: modular, readable, debuggable, top-down design.
🌍 Portable
The same source runs on Windows, Linux, a phone chip or a supercomputer — just recompile. That is why UNIX spread everywhere.
📚 Rich Library
Hundreds of ready functions in stdio.h, math.h, string.h, stdlib.h and more.
👉 Pointer & Memory Power
Direct access to memory via & and *, plus dynamic allocation — the heart of data structures.
🔁 Rich Operators & Extensible
Arithmetic, logical, bitwise, ternary, assignment… and you can write your own functions and libraries to reuse anywhere.
⚠️ Honest limitations (adds marks to any answer)
C has no runtime checking (out-of-range array access silently corrupts memory), no garbage collection (free what you malloc), no OOP (no classes/inheritance) and no exception handling (no try/catch). C++ and Java were invented to fix exactly these gaps.

1.6 Structure of a C Program

Every complete C program is built from six sections. Only main() is compulsory — but professional programs use all six.

1 Documentation
Name, author, date, purpose — as comments.
2 Link
#include header files (stdio.h, conio.h…)
3 Definition
#define constants & macros.
4 Global Declaration
Global variables + function prototypes.
5 main() Function
Compulsory entry point: declaration part + executable part.
6 Sub Programs
User-defined functions, called from main().

A program showing ALL six sections

structure_demo.c
/* =============================================
   1. DOCUMENTATION SECTION
   Program : structure_demo.c
   Purpose : shows all 6 sections of a C program
   ============================================= */

/* 2. LINK SECTION */
#include <stdio.h>

/* 3. DEFINITION SECTION - symbolic constants */
#define PI 3.14159
#define MAX 100

/* 4. GLOBAL DECLARATION SECTION */
float area;               /* global variable     */
int square(int n);        /* function prototype  */

/* 5. main() FUNCTION - execution starts here */
int main()
{
    /* 5a. declaration part */
    int r = 5, result;

    /* 5b. executable part */
    area = PI * r * r;
    result = square(r);

    printf("Area of circle = %.2f\n", area);
    printf("Square of %d = %d\n", r, result);

    return 0;      /* 0 = success */
}

/* 6. SUB PROGRAM SECTION */
int square(int n)
{
    return (n * n);
}
▸ Output
Area of circle = 78.54
Square of 5 = 25
1. Documentation Section
A set of comments describing the program name, author, date and purpose, written between /* ... */. The compiler ignores it completely — it exists for humans.
2. Link Section
Tells the preprocessor to include header files that declare library functions. No printf() without #include <stdio.h>. These lines take no semicolon.
3. Definition Section
Defines symbolic constants via #define. The preprocessor text-replaces them before compiling, so they occupy no memory and can never change at runtime.
4. Global Declaration Section
Variables and function prototypes declared outside every function. A global variable is usable by every function from its declaration point onward.
5. main() Function
The compulsory section and entry point of every C program. Split into a declaration part (variables first) and an executable part (the actual statements).
6. Sub Program Section
All user-defined functions (subroutines/modules). They are prototyped in section 4, defined here, and called from main() — this is what makes C modular.
✨ The two golden rules of main()
1. Every C program must have exactly one main() — more than one, or none, is a compile error.
2. Execution always starts at the first statement of main(), no matter how many other functions exist, and ends when main() returns.

B. Formatting conventions

✅ Always do this

  • Indent every { } block by 4 spaces
  • One statement per line
  • Spaces around operators: a = b + c
  • Blank line between logical sections
  • Comment above every function with /* */

🎓 Important Exam Questions (tap for answers)

1. Who developed C, when, where and why was it created?
Dennis M. Ritchie developed C in 1972 at Bell Telephone Laboratories, Murray Hill, New Jersey, USA. The goal was to rewrite the UNIX operating system in a high-level language so it could be ported to new machines instead of being rewritten in assembly every time.
2. Explain the evolution of C from ALGOL to ANSI C.
ALGOL 60 (1960, international committee) was structured but too abstract → CPL (1963, Cambridge & London) → BCPL (1967, Martin Richards) was small and typeless → B (1969-70, Ken Thompson) adapted BCPL for UNIX on a PDP-7 → C (1972, Ritchie) added data types, arrays, structures and pointers; UNIX was rewritten in it in 1973. Kernighan & Ritchie documented C in 1978; ANSI standardised it as C89 in 1989 (ISO C90), followed by C99, C11, C17 and C23.
3. Draw and explain the structure of a C program.
Six sections: (1) Documentation — comments about name/author/purpose; (2) Link — #include header files; (3) Definition — #define constants; (4) Global declaration — global variables and function prototypes; (5) main() — the compulsory entry point with a declaration part and an executable part; (6) Sub programs — user-defined functions. Execution always starts at the first statement of main().
4. Explain the stages in the execution of a C program.
(i) Editing — source written in a .c file; (ii) Preprocessing — #include/#define expanded into a .i file; (iii) Compilation — C converted to assembly (.s), syntax errors reported; (iv) Assembly — object code (.o) produced; (v) Linking — object code joined with library code into an executable; (vi) Loading — the loader places the program in memory and execution starts at main().
5. Why is C called a middle-level language?
It combines high-level features — English-like syntax, functions, structures, portability — with low-level features — bitwise operators, pointer arithmetic, direct memory access — so the same language can write applications and system software like OS kernels and drivers. Hence neither purely high-level nor purely low-level.
6. List the C character set with the count of each group.
(a) Alphabets — 52 (A-Z, a-z); (b) Digits — 10 (0-9); (c) Special symbols — 29; plus white-space characters (space, tab, newline, carriage return). Printable total 91; with the 4 common white spaces, 95. All are based on ASCII.
7. What are the six types of tokens? Give two examples of each.
(1) Keywords — int, while; (2) Identifiers — marks, total_sum; (3) Constants — 100, 'A'; (4) Strings — "Hello"; (5) Operators — +, &&; (6) Special symbols — ;, {}.
8. Differentiate syntax, runtime and logical errors.
A syntax error breaks C's grammar rules and is caught by the compiler — the program never compiles (missing semicolon). A runtime error appears while the program runs and usually crashes it (division by zero). A logical error is a flaw in the logic — the program compiles and runs but gives the wrong output; only testing reveals it.

2.1 Identifiers

An identifier is a name given to a variable, function, array or any other user-defined entity. It lets us refer to memory locations and code blocks with human-friendly words.

Rules for naming identifiers

  1. Must begin with a letter (A-Z, a-z) or an underscore (_).
  2. After the first character: letters, digits or underscores only.
  3. Cannot start with a digit (2total is wrong).
  4. Cannot contain spaces or special symbols except _ (my-name, user@name are wrong).
  5. Cannot be a keyword (int float; is a compile error).
  6. C is case-sensitive: Age, age and AGE are three different identifiers.
  7. Traditionally the first 31 characters are significant (ANSI C rule).

✅ Valid identifiers

  • age — simple word
  • _count — starts with underscore
  • student_name — words joined by _
  • rollNo123 — letters then digits
  • MAX_SIZE — constant style

❌ Invalid identifiers

  • 2ndValue — starts with a digit
  • user@name — special character
  • total sum — contains a space
  • float — it is a keyword
  • my-name — hyphen not allowed
💡 Underscore rule (extra marks)
Names beginning with an underscore followed by an uppercase letter, or with two underscores (like __count), are reserved by the system library — avoid them in your own programs.

2.6 Variables

A variable is a named memory location whose value can change during execution. Before using it you must declare it so the compiler reserves the right memory.

Tells the compiler the name and type: int x; — no value given.
Initialization
Starting value at declaration time: int x = 5;
Assignment
Changing the stored value later: x = 20;
Definition vs declaration
A definition reserves memory; a plain declaration only describes the name/type. Every definition is a declaration, but not every declaration is a definition.

1. Declare before use. 2. Locals die when their block ends; globals live until the program ends. 3. A local with the same name as a global shadows it inside its function. 4. Global variables can be given initial values; locals too (both are fine).

• Last digit: n % 10. Remove last digit: n / 10 — these two power every "sum of digits" and "reverse a number" program.

🎓 Short-circuit rule (2-mark answer)
In &&, if the LEFT operand is false the whole expression is false, so the right side is never evaluated. In ||, if the LEFT operand is true the right side is never evaluated. This is why the division above never crashes — and it is also why order matters in logical expressions.

3.11 Type Conversion (Implicit & Explicit)

When an expression mixes types, C automatically converts (promotes) the smaller type to the bigger one — this is implicit conversion. Converting by hand with (type) is explicit conversion (casting).

conversion.c
#include <stdio.h>

int main()
{
    int a = 5, b = 2;

    float r1 = a / b;              /* 2.00 - int division FIRST! */
    float r2 = (float)a / b;       /* 2.50 - explicit cast */
    float r3 = 5.0 / b;            /* 2.50 - implicit promotion */

    printf("r1 = %.2f\n", r1);
    printf("r2 = %.2f\n", r2);
    printf("r3 = %.2f\n", r3);

    int t = (int)3.9;              /* 3 - casting truncates */
    int u = a + 0.9;               /* a promoted to float,
                                       result 5.9 → stored as 5 */
    printf("t = %d, u = %d\n", t, u);

    return 0;
}
▸ Output
r1 = 2.00
r2 = 2.50
r3 = 2.50
t = 3, u = 5
💡 The promotion ladder
char/short → int → long → float → double. In int + float the int becomes float before adding. And remember: converting float → int always truncates (3.99 → 3), it never rounds.

🎓 Important Exam Questions (tap for answers)

1. Classify the operators of C with examples.
By purpose: arithmetic (+ − * / %), relational (== != > < >= <=), logical (&& || !), assignment (= += −= *= /= %=), increment/decrement (++ −−), bitwise (& | ^ ~ << >>), ternary (?:), and special (sizeof, comma, &, *, cast). By operand count: unary (−a, !x, sizeof), binary (a+b), ternary (?: only).
2. Difference between = and ==?
= is assignment — it stores the right value into the left variable and itself returns a value. == is equality comparison — it returns 1 or 0. Writing if (x = 5) assigns instead of comparing, making the condition always true (x becomes 5, non-zero).
3. Explain prefix and postfix increment with an example.
Prefix (++a): increment first, then use the new value. Postfix (a++): use the old value first, then increment. With a = 5: b = ++a gives a = 6 and b = 6; but b = a++ gives b = 5 and then a = 6.
4. What is short-circuit evaluation? Give an example.
In a logical expression the right operand is evaluated only when needed: for &&, if the left is false the whole result is false, so the right side is skipped; for ||, if the left is true the right side is skipped. Example: if (b != 0 && a/b > 1) — when b is 0 the division never executes, avoiding a crash.
5. What are operator precedence and associativity? Explain with examples.
Precedence decides which operator is evaluated first in an expression with several operators; associativity decides the direction of evaluation for operators of the same precedence. In a + b * c, * wins so b*c is computed first (10+15=25 for a=10,b=5,c=3). In a − b − c, − is left-associative so (a−b)−c. Assignment is right-associative, which is why a = b = 5 works.
6. Differentiate implicit and explicit type conversion.
Implicit conversion is automatic: when mixed types meet, the smaller is promoted (char→int→long→float→double), e.g. int + float converts the int to float first. Explicit conversion (type casting) is written by the programmer as (type)value, e.g. (float)a/b forces float division. Casting a float to an int truncates the fractional part.
7. Differentiate lvalue and rvalue with examples.
An lvalue refers to a named location in memory — it has an address and can stand on the left of an assignment, e.g. variable x, array element a[2], *p. An rvalue is a value without an address — a temporary such as a constant (5), a literal ('A') or an expression (a+b) — it can only stand on the right. Only modifiable lvalues can appear on the left of =.
8. Evaluate: 10 + 3 * 4 − 6 / 3.
Step 1: multiplications/divisions: 3*4 = 12 and 6/3 = 2. Step 2: left to right: 10 + 12 − 2 = 22 − 2 = 20.

1. Explain getchar() and putchar() with an example.

(4) default (optional) executes when no case matches. (5) Multiple case labels may share one block for grouped values.
5. Explain fall-through in switch with an example.
When a case has no break, execution continues into the following cases instead of leaving the switch. With x = 2 in switch(x){ case 1: …; case 2: …; case 3: …; }, cases 2, 3 and default all run. It is usually a bug, but deliberately stacking case labels lets several values share one block.
6. When should you use switch instead of if-else?
Use switch when testing ONE integer/char variable against several fixed constant values — it is cleaner and often faster (jump table). Use if-else for relational or range conditions (x > 10, 40 <= marks < 60), float comparisons, or conditions combining several variables.
7. Convert this if-else to ternary: if (a>b) max=a; else max=b;
max = (a > b) ? a : b; — the condition a>b selects a when true, otherwise b. Nested ternaries can even find the largest of three: max = (a>b) ? ((a>c) ? a : c) : ((b>c) ? b : c);

6.1 Why Loops?

A loop repeats a block of statements while a condition is true. Without loops, printing 1 to 100 would need 100 printf lines! Loops come in two flavours:

🔢 Counter-controlled
The repetition count is known in advance — "print 1 to 10", "sum the first 100 numbers". Best with for.
🚩 Sentinel-controlled
Repetition ends when a special sentinel value arrives — "keep adding until the user types 0". Best with while or do-while.

6.2 The for Loop

for ( initialization ; condition ; update )
{
    /* body — repeats while condition is true */
}

Execution order (learn for trace questions)

  1. Initialisation runs ONCE (e.g. i = 1).
  2. Condition is checked (e.g. i <= 5). If false → exit the loop.
  3. If true → run the body.
  4. Run the update (e.g. i++).
  5. Jump back to step 2.
for_basic.c
#include <stdio.h>

int main()
{
    int sum = 0;

    for (int i = 1; i <= 100; i++)
        sum = sum + i;

    printf("Sum of 1..100 = %d\n", sum);   /* 5050 */
    return 0;
}

for-loop variations

for (i = 10; i > 0; i--)         /* count down        */
for (i = 2; i <= 20; i += 2)      /* step by 2         */
for (i = 0, j = 10; i < j; i++)   /* two counters      */
for (;;)                         /* infinite loop!    */
int i; for (i = 0; i < 5; i++);   /* empty body — bug! */
⚠️ Two classic for mistakes
1. A semicolon right after for(...) creates an empty body: for (i=0; i<5; i++); does nothing five times.
2. Wrong condition direction — i >= 0 with i++ never becomes false → infinite loop. Check your < and >!

6.4 The do-while Loop (Exit-Controlled)

do
{
    body;        /* runs AT LEAST ONCE */
} while (condition);   /* checked AFTER — note the semicolon! */

Menu-driven program — the perfect do-while case

menu.c
#include <stdio.h>

int main()
{
    int choice;
    do
    {
        printf("\n=== MENU ===\n");
        printf("1. Play  2. Help  3. Exit\n");
        printf("Choice: ");
        scanf("%d", &choice);

        switch (choice)
        {
            case 1: printf("Playing...\n"); break;
            case 2: printf("Help text...\n"); break;
            case 3: printf("Bye!\n"); break;
            default: printf("Invalid choice\n");
        }
    } while (choice != 3);

    return 0;
}
✨ Why do-while for menus?
The menu must be shown at least once BEFORE we know the user's choice — exactly what do-while guarantees. A plain while might skip the menu entirely if its condition starts false.

⚠️ goto rules
goto can only jump inside the same function, and never jump into a block or a loop (you would enter with uninitialised state). Modern code prefers break/continue or a flag variable — goto is a last resort and most style guides ban it.
💡 break in nested loops
break exits only the innermost loop. The outer loop keeps running — to stop everything, break each level, use a flag, or (last resort) goto.

🎓 Important Exam Questions (tap for answers)

1. What is a loop? Name the three loops of C with their type.
A loop is a control structure that repeats a block while a condition is true. C has: for and while — both entry-controlled (condition checked before the body; the body may never run) and do-while — exit-controlled (condition checked after the body, so it runs at least once; needs a semicolon after while(cond)).
2. Explain the structure and execution order of the for loop.
for (init; condition; update) { body; }. Execution: (1) init runs once; (2) condition is tested — if false, exit; (3) body executes; (4) update executes; (5) return to step 2. All three parts are optional; for(;;) is an infinite loop.
3. Differentiate while and do-while.
while tests the condition BEFORE the body (entry-controlled), so the body may never execute. do-while executes the body FIRST and tests the condition AFTER (exit-controlled), guaranteeing at least one execution; it also requires a semicolon after while(cond). do-while is ideal for menus that must display at least once.
4. Differentiate break and continue with examples.
break immediately TERMINATES the innermost loop (or switch) and control moves to the statement after it — e.g. exit when i == 6. continue SKIPS only the remaining statements of the current iteration and jumps to the next iteration — e.g. skip even numbers when printing 1..10. Neither affects outer loops in nesting.
5. What is a nested loop? Explain with the multiplication table.
A nested loop is a loop inside another loop; the inner loop completes all its iterations for each single iteration of the outer loop, giving m × n total runs. In the table program the outer i selects a row 1..5 while the inner j runs 1..5 printing i*j across each row — producing the 5×5 multiplication table.
6. What causes an infinite loop? How do you avoid it?
Causes: forgetting the update expression, updating in the wrong direction (i-- with i < 10), a permanently true condition like while(1), or a misplaced semicolon creating an empty body. Avoidance: make sure every iteration moves the loop variable towards making the condition false, and use break only with a well-defined exit case.
7. Trace: for (i = 1; i <= 3; i++) printf("%d ", i * i);
i = 1: condition true → prints 1. i = 2 → prints 4. i = 3 → prints 9. i = 4 → condition false, exit. Output: 1 4 9.
8. What is goto? When (if ever) should it be used?
goto label; transfers control to the labelled statement anywhere in the same function. It cannot jump into a block or a loop. It is rarely needed — break/continue and flag variables handle almost all cases — but its one clean use is breaking out of multiple nested loops at once. Most style guides discourage it because goto makes control flow hard to follow.
